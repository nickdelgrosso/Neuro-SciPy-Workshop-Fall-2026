


# Course: "Intro to Scientific Programming with Python"

In this virtual hands-on workshop, we will explore the Python and Pandas data analysis ecosystem in depth, applying them to data analysis of a real-world experiment! Libraries like Numpy, XArray, Seaborn, Pingouin, and Matplotlib will help span the data analysis path between processed data and final results. At the end of each session, all interactive Jupyter notebooks that explore the tools introduced that day will be available for further independent learning and review, with teacher available to answer questions and extra homework assignments provided to help digest the new material.

## Preparing for the Course

### 1. Install Software

Below are the three pieces of software we'll be relying on for the course: `uv`, `VSCode`, and `git`.  We'll learn a lot about these three programs and how they are used for working in Python throughouth the course, so don't worry if they are new to you.  Just try and get them installed before the first day so that we can make the most of the in-class time:

  - [ ] **Getting Python**: Install the [UV Python Package Manager](https://docs.astral.sh/uv/getting-started/installation/#standalone-installer); this will be our go-to system for downloading Python and each day's relavent computational packages.
    - To Check if it's installed, run `uv --version` in your terminal to confirm it is installed; you should see an output like `uv 0.12.19 (bea138450 2026-09-24 x86_64-pc-windows-msvc)` (exact version doesn't matter)
    - note: if you already use another package manager that supports virtual environments, like Pixi, Conda, or Poetry, and are comfortable using it, you are welcome to use this for the course.

  - [ ] **Getting Course Materials**: Install the [`Git`](https://git-scm.com/install/) Version Control System; this will be our go-to course materials download system for the course. 
    - To check if it's installed, run `git --version` in your terminal; you should see an output like `git version 2.55.0.windows.5` or similar (exact version doesn't matter)
    
  - [ ] **Getting Coding Environment**: Install [Visual Studio Code](https://code.visualstudio.com/Download); this will be our go-to editor for the course 
    - note: if you already use another Jupyter-Supporting Python coding environment, like PyCharm or Jupyter Lab and are comfortable using it, you are welcome to use this for the course.


> **Having Trouble with this Software?  No Worries!**: Cloud links are provided for all of the course materials, so you can also do the exercises inside the browser without installing anything.
